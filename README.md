# Agent → Obsidian

把 AI Agent 的对话、工作过程和每日分析整理进 Obsidian。

这是一套面向不同 Agent 的工作归档方法：保留完整记录，写每日综合，更新项目与主题笔记，再把有用的经验整理成可以复用的方法。记录来自哪个 Agent，就在来源中注明；同一项目的内容放在一起。

Agent 负责读取材料、分析和写入 Markdown，Obsidian 保存与连接笔记。仓库提供通用的 [SKILL.md](SKILL.md)，以及一个完整的 [Codex 示例](examples/codex/README.md)。

## 开始使用

把下面的要求交给你正在使用的 Agent，并提供本地 Obsidian vault 的位置和需要整理的记录：

```text
按照 https://github.com/rrrrrredy/agent-obsidian 中的方法，
把今天的 Agent 对话和工作记录整理到我的 Obsidian。
阅读完整材料，写好每日综合，保留原文与工具过程的链接，
更新相关项目笔记，并提炼值得复用的方法。
已有目录和同步方式继续使用。
```

支持 skills 的环境可以将本仓库放入其技能目录，以 `agent-obsidian` 调用；其他环境可以直接把 [SKILL.md](SKILL.md) 作为任务说明。使用当前环境已有的会话读取、文件访问或导出能力取得记录。导出的 Markdown、JSON、JSONL、文本和工具日志都可以作为整理材料。

已有 Obsidian 库继续使用原目录和分类。记录放在远端或另一台设备时，先通过现有连接或导出文件取得，再写入目标 vault。

## 通用方法

1. **确定范围。** 指定要整理的会话、项目和日期，沿用已有 vault、时区、分类和同步方式。
2. **保留原文。** 保存用户要求、Agent 回复、工具过程、错误与修复、实际产物；为记录保留来源、时间和稳定链接。
3. **阅读全文。** 按日期和项目读取材料，把同一任务的后续对话、子任务和迟到记录接回上下文。
4. **写每日综合。** 写清当天做成了什么、判断依据是什么、认识如何变化、问题怎样解决，以及哪些经验可以继续使用。
5. **更新长期笔记。** 将结果合入项目和主题笔记，把有实际内容的方法、提示词与任务材料单独整理，并链接回原文。
6. **合并与同步。** 保留既有笔记和批注，将新增内容写入 vault，再沿用已有同步方式。定时整理使用当前环境的调度能力。

接入另一个 Agent 时，调整记录的取得方式和字段对应关系即可：谁说了什么、何时发生、做了什么、产出在哪里。归档结构、阅读方法和写作要求保持一致。

## 会留下什么

| 内容 | 呈现方式 |
| --- | --- |
| 提示词、回复、补充要求 | 可直接阅读的完整对话 Markdown |
| 工具调用、错误与修复 | 可读过程记录，链接到原始事件或日志 |
| 决策与修订 | 项目笔记中的经过、依据、反馈和原文链接 |
| 每日综合 | 覆盖当天所有主题的分析文章 |
| 长期认识与方法 | 持续更新的主题笔记、提示词和可复用材料 |
| 数据集、任务、环境、评测 | 从实际工作材料中整理的对应资产与说明 |

每日综合由 Agent 阅读材料后写作，覆盖成果、判断依据、观点变化、经验和新方向。采集脚本负责取得记录和去重。

## 如何接通

```text
Agent 会话、导出文件、工具日志与工作产物
        ↓
通过当前环境的读取能力或对应来源的采集脚本取得材料
        ↓
Agent 阅读、分析、归类，写入本地 Obsidian vault
        ↓
已有同步方式（如 Obsidian Sync）
```

直接写本地 Markdown 就可以整理笔记，无需额外社区插件。需要远端同步时沿用已有配置；官方 Sync 的接入说明见 [连接与同步](SKILL.md#连接与同步)。

## 目录起点

```text
Agent汇总/
  01-每日汇总/YYYY/YYYY-MM/YYYY-MM-DD/
  02-完整对话/
  03-项目与任务/
  04-知识与认识/
  05-复用材料/
  06-数据集/
  07-任务包/
  08-环境/
  09-评测/
  10-原始资料与附件/
  11-模板与索引/
```

已有分类优先；新库可从这套结构开始，按材料逐步增加文件。每个日期有自己的综合文章与索引；不同 Agent 的记录按项目和主题合并，来源作为笔记属性保留。

## Codex 示例

[examples/codex/](examples/codex/README.md) 展示这套方法如何用于 Codex，包含：

- 通过 skill 使用通用归档方法的操作说明。
- 读取本地 `sessions` 与 `archived_sessions` 的零依赖 Node.js 采集脚本。
- 完整对话 Markdown、工具轨迹、稳定事件链接和增量阅读计划。
- 主任务、跨日子任务、已归档会话的演示数据，以及每日综合示例。

Codex 的会话路径、日志字段和调用方式都放在这个示例中。其他 Agent 使用自己的记录入口，并按同样的方法整理笔记。

## 日常使用

可以要求 Agent “每天18:00整理”，由当前环境已有的定时能力执行采集、阅读、综合、归类、写入与同步。本地任务在设备可运行时执行，恢复后按原日期补齐遗漏内容。

媒体密集项目可以保留完整原件、同步关键材料与索引；普通项目按原定范围归档。整理过程中沿用现有项目的开发规则。
